뉴스레터 제목

스티비에서 편집하는 순서

  1. 스티비용 HTML 복사를 누릅니다. 안내 영역을 제외한 실제 메일 본문만 복사됩니다.
  2. 스티비에서 새 이메일을 만들고 HTML 직접 편집 영역에 붙여 넣습니다.
  3. 제목과 프리헤더를 확인하고, 이미지가 모두 HTTPS 주소로 표시되는지 점검합니다.
  4. 데스크톱·모바일 미리보기를 확인한 뒤 Outlook 계정으로 테스트 발송합니다.
  5. 테스트 메일의 링크, 이미지 다운로드 전후 화면, 수신거부 링크를 확인한 뒤 발송합니다.

Outlook 최적화 기준

  • 레이아웃은 표 기반이며, 폭·정렬·여백·글꼴을 각 요소의 인라인 스타일로 지정했습니다.
  • 본문 폭은 640px로 고정하고 바깥 표의 align="center"로 중앙 정렬했습니다.
  • 기본 글꼴은 Pretendard, Noto Sans KR, Malgun Gothic, Arial 순서입니다. 다만 Outlook은 웹폰트를 안정적으로 불러오지 않으므로, 수신자 PC에 Pretendard가 없으면 Malgun Gothic 또는 Arial로 표시됩니다.
  • 이미지는 공개 HTTPS 주소와 명시적 너비를 사용하며, 중요한 문구를 배경 이미지 안에 넣지 않았습니다.
  • 섹션 배경색은 bgcolor와 인라인 background-color를 함께 사용했습니다.
  • JavaScript, 외부 스타일시트, 웹폰트, flex/grid 레이아웃은 실제 메일 본문에 포함하지 않았습니다.
발송 전 확인: 「고객 이야기 · 롯데홈쇼핑」은 롯데홈쇼핑 확인 전 검토본입니다. 실명 인용을 포함한 승인 범위를 확인하고, 「고객사례 전문 보기」 링크를 정식 공개 주소로 바꾼 뒤 발송하세요. 승인 전에 발송해야 한다면 이 섹션과 도입부 마지막 문장을 빼야 합니다.
주의: 브라우저와 Outlook은 서로 다른 렌더링 엔진을 사용하므로 픽셀 단위로 완전히 같게 보장할 수 없습니다. 이 원본은 글꼴 대체, 섹션 정렬, 표 레이아웃과 이미지 크기가 무너지지 않는 것을 우선합니다.

AI Agent의 확산,
이제는 연결과 운영까지 관리해야 할 때
롯데홈쇼핑은 XGEN으로 만든 업무용 AI Agent를 4개 부서로 넓혀 가고 있습니다. 이번 호에서는 이 사례와 함께, 늘어나는 에이전트와 연결 도구를 관리하기 위한 XGEN의 11월 업데이트를 소개합니다.
AI Agent가 실제 업무를 처리하려면 메일, 문서, 사내 시스템 같은 도구와 연결되어야 하고, 이 연결에는 표준 프로토콜인 MCP(Model Context Protocol)가 쓰입니다. 연결이 늘어날수록 운영 담당자는 어떤 에이전트가 어떤 도구를 쓰는지, 특정 서버를 내리면 어떤 업무가 멈추는지 파악할 수 있어야 합니다.

XGEN은 11월에 MCP 관리 기능을 [MCP 서버 관리]와 [MCP 카탈로그 관리] 두 화면으로 새로 구성해 검증 환경에 반영했습니다. 11월 12일 운영 릴리즈에는 지난 호에서 안내한 보안 개선 3건을 반영했습니다. 업무별 AI Agent를 여러 부서로 넓혀 가는 롯데홈쇼핑의 사례도 함께 전합니다.

기본 제공 MCP 카탈로그
호출 기록과 대시보드. XGEN 서버를 거치는 MCP 호출을 한 지점에서 기록합니다. 호출마다 사용자, 에이전트, 도구, 성공 여부, 호출 위치가 남고, 90일 동안 조회하거나 엑셀로 내려받을 수 있습니다. 대시보드에서는 호출 수, 오류율, 응답 시간과 많이 쓰는 도구·에이전트 순위를 확인합니다.
도구에 넘긴 값과 결과, 개인 변수 값은 저장하지 않으며, 기록 저장에 실패해도 호출은 그대로 진행됩니다.
사용처 확인. 서버 설정을 바꾸거나 내리기 전에, [사용처]에서 이 서버를 쓰는 에이전트와 배포 상태를 먼저 확인할 수 있습니다.
공용 변수와 개인 변수. 모두가 같이 쓰는 값은 공용 변수로, 사람마다 다른 값(예: 각자의 Google 계정)은 개인 변수로 나눕니다. MCP 서버 코드를 고치지 않고도 같은 서버를 사용자마다 자기 계정으로 쓸 수 있습니다.
MCP 카탈로그. 사용자 PC에 설치하는 MCP는 데스크톱 앱 DexOn이 맡습니다. 관리자가 카탈로그에 설치 방법을 정의해 두면, 사용자는 변수만 입력하면 됩니다. GitHub, Notion, Jira·Confluence 등 14종을 버전을 고정해 기본으로 제공합니다.
[MCP 카탈로그 관리] 기본 제공 MCP 14종과 항목별 설치 현황입니다. (개발 환경)
