PLATEER AI LABS · Outlook 서명

파란 점선이 보이는 곳은 클릭해서 바로 수정할 수 있습니다. 수정한 뒤 [서명 복사] → Outlook 서명 편집기에 Ctrl+V.

1 · 새 Outlook (Windows 11 기본)
  1. 이 페이지에서 수정할 항목을 클릭해 내용을 바꿉니다. 이메일을 바꾸면 mailto: 링크도 자동으로 따라갑니다.
  2. [서명 복사] 클릭 — 색상·굵기·구분선·링크가 모두 포함된 상태로 복사됩니다.
  3. Outlook 우측 상단 ⚙ 설정 → 계정 › 서명
  4. 이 설정 적용 대상에서 서명을 넣을 계정을 고릅니다. 계정이 여러 개면 계정마다 따로 등록해야 합니다.
  5. + 서명 추가 → 맨 위 칸에 서명 이름(예: 본인 이름)을 적고, 아래 편집 영역에 Ctrl+V.
  6. 아래 새 메시지에 대한 기본값 설정을 체크하고 저장.
2 · 클래식 Outlook (파일 메뉴가 있는 버전)
  1. 파일 › 옵션 › 메일 › 서명
  2. 새로 만들기로 서명을 추가하고 편집 영역에 Ctrl+V.
  3. 붙여넣기 직후 서식 옵션이 뜨면 원본 서식 유지를 선택합니다. (새 Outlook에서는 이 옵션이 뜨지 않습니다 — 그냥 Ctrl+V 하면 됩니다.)
  4. 우측 새 메시지 드롭다운에서 방금 만든 서명을 선택하고 확인.
3 · 붙여넣은 뒤 확인할 것
  1. M · T · E 라벨이 굵게 나오는지.
  2. 직책·전화번호 끝에 밑줄이 없는지.
  3. 배경이 흰색인지 (회색 블록이면 붙여넣기가 덜 된 것 — 지우고 다시 복사).
  4. 구분선이 하늘색 실선인지, 하단 링크 두 개가 파란색인지.
  5. 회신·전달에도 서명을 넣으려면 서명 화면의 회신 및 전달의 기본값을 (서명 없음)에서 방금 만든 서명으로 바꿔야 합니다. 기본값은 서명 없음입니다.
4 · 자주 나오는 질문
  1. M·E 아래 빨간 물결선이 보입니다. Outlook 맞춤법 검사기가 한 글자를 단어로 인식해 표시하는 것으로, 작성 창에서만 보이고 수신자가 받는 메일에는 나타나지 않습니다. 작성 중에도 숨기려면 Outlook의 검토 › 언어 › 자동 맞춤법 검사를 끄세요.
  2. 모바일 Outlook에서 서명이 다릅니다. 모바일 앱은 PC 서명과 별도로 저장됩니다. 앱 설정에서 따로 붙여넣어야 합니다.
  3. 글자가 커지거나 작아집니다. 붙여넣은 뒤 서명 전체를 선택해 글꼴 크기를 바꾸지 마세요 — 줄마다 크기가 다르게 지정돼 있어 한꺼번에 바꾸면 균형이 깨집니다.

서식이 걸러지지 않도록 적용한 것
· 레이아웃 전체를 <table> + 인라인 스타일로만 구성 — Outlook은 Word 렌더링 엔진을 쓰므로 div/flex/외부 CSS는 무시됩니다.
· 굵기는 font-weight 대신 <b> 태그로 지정 — 스타일이 제거돼도 굵기가 남습니다.
· 색상은 <a>와 내부 <span>에 이중 지정 — Outlook이 링크색을 기본 파랑/보라로 덮어쓰는 것을 막습니다.
· 구분선은 ━ 문자가 아니라 1행 1열 표의 아래 테두리(#00ABEF 1.5pt) — 폰트·환경에 따라 두께가 변하지 않습니다.
· letter-spacing·flex·margin 등 Word가 버리는 속성은 쓰지 않았습니다. 여백은 padding과 표 구조로만 만들었습니다.
· 글꼴은 맑은 고딕 → Malgun Gothic → Arial 순으로 대체 지정했습니다.
