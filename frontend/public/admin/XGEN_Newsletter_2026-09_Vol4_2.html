스티비 HTML 편집·Outlook 최적화 안내

아래 뉴스레터는 스티비 HTML 편집기에 붙여 넣도록 만든 발송용 원본입니다. 웹 미리보기 전체 소스를 복사하지 말고, 반드시 아래 버튼으로 뉴스레터 본문만 복사하세요.

스티비 도움말 열기 Outlook HTML 형식 안내 Outlook CSS 지원표

스티비에서 편집하는 순서

  1. 스티비용 HTML 복사를 누릅니다. 안내 영역을 제외한 실제 메일 본문만 복사됩니다.
  2. 스티비에서 새 이메일을 만들고 HTML 직접 편집 영역에 붙여 넣습니다.
  3. 제목과 프리헤더를 확인하고, 이미지가 모두 HTTPS 주소로 표시되는지 점검합니다.
  4. 데스크톱·모바일 미리보기를 확인한 뒤 Outlook 계정으로 테스트 발송합니다.
  5. 테스트 메일의 링크, 이미지 다운로드 전후 화면, 수신거부 링크를 확인한 뒤 발송합니다.

Outlook 최적화 기준

  • 레이아웃은 표 기반이며, 폭·정렬·여백·글꼴을 각 요소의 인라인 스타일로 지정했습니다.
  • 본문 폭은 700px로 고정하고 바깥 표의 align="center"로 중앙 정렬했습니다.
  • 기본 글꼴은 Arial, Malgun Gothic, Apple SD Gothic Neo 순서입니다.
  • 이미지는 공개 HTTPS 주소와 명시적 너비를 사용하며, 중요한 문구를 배경 이미지 안에 넣지 않았습니다.
  • 섹션 배경색은 bgcolor와 인라인 background-color를 함께 사용했습니다.
  • JavaScript, 외부 스타일시트, 웹폰트, flex/grid 레이아웃은 실제 메일 본문에 포함하지 않았습니다.
주의: 브라우저와 Outlook은 서로 다른 렌더링 엔진을 사용하므로 픽셀 단위로 완전히 같게 보장할 수 없습니다. 이 원본은 글꼴 대체, 섹션 정렬, 표 레이아웃과 이미지 크기가 무너지지 않는 것을 우선합니다.

감사합니다.

XGEN DeX · 노드 대신, 대화로 만듭니다.

기업의 AI Agent가 실제 업무를 수행하려면 서버뿐 아니라 사용자의 PC에 있는 파일과 프로그램에도 안전하게 연결돼야 합니다. XGEN DeX는 서버 Agent를 데스크톱으로 확장해 로컬 파일·프로그램·연산 자원을 활용하고, 복잡한 노드 설계 대신 대화로 Agent를 구성하도록 합니다.

데스크톱 앱, 터미널 CLI, VS Code 확장이 하나의 코어를 공유하며 인증·권한·감사는 서버 정책을 따릅니다. 비교적 경량인 오픈 모델만으로도 실제 업무를 완료하는 환경을 만드는 것이 목표입니다.

DeX Connector를 통해 서버 Agent와 로컬 앱·스토리지·사내 시스템을 연결합니다.
데스크톱 앱에서 Agent 대화와 로컬 CPU·GPU·RAM 상태를 함께 확인합니다.
터미널 CLI에서도 Agent 선택, 대화와 실행 상태 확인이 가능합니다.
VS Code 확장은 dex-cli를 통해 로컬 작업 폴더와 연결됩니다.

기술 뉴스

01

구글 A2A가 MCP 곁으로, 에이전트 표준 둘이 한 재단에 모였다

도구 연결 표준 MCP와 Agent 간 협업 표준 A2A가 같은 중립 재단에서 관리됩니다. 기업은 플랫폼 내부 통합성과 외부 Agent 상호운용성 사이에서 개방 범위와 통제 원칙을 함께 설계해야 합니다.

02

GLM-5.3이 오픈웨이트로 풀렸다, 코딩·보안 벤치서 프런티어에 붙었다

오픈 모델의 코딩·보안 성능과 비용 경쟁력이 빠르게 높아지고 있습니다. 경쟁력의 중심은 모델 자체보다 새 모델을 빠르게 검증·서빙하고 통제 아래 두는 운영 체계로 이동합니다.

03

Qwen3.8이 통째로 열렸다, 27B가 Apache 2.0, 우리도 이미 돌린다

Qwen3.8-27B는 XGEN 개발 환경에서도 검증 중입니다. 고객 환경 적용 전에는 한국어 성능, FP8 안정성, 모델 출처와 폐쇄망 운영 요건을 함께 확인해야 합니다.

읽을거리

AI는 좋은 팀을 더 빠르게, 엉킨 팀을 더 엉키게 한다

AI는 조직의 소통과 프로세스를 그대로 증폭합니다. 도입 기술만큼 적용할 업무와 순서를 먼저 정하는 일이 중요합니다.

LLM 기억을 만들려다 프로그램 분석 엔진이 됐다

벡터 검색은 관련성은 찾지만 사실이 아직 유효한지는 판단하지 못합니다. 오래 쓰는 Agent일수록 사실 변경과 결론 무효화를 관리하는 구조가 필요합니다.

자연어 대신 의사코드로 코딩한다 — Huzzah

의도를 의사코드로 저장하고 변경분만 모델에 전달하는 실험입니다. 코드와 요구사항 중 무엇을 원본으로 둘지 생각하게 합니다.
